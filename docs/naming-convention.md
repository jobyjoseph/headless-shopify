# Naming Convention

Naming conventions in a codebase ensure consistency, clarity and predictability.

## React Components

Use UpperCamelCase for component names and their respective file names.

```
// Header.js
const Header = () => (
    <header>
        <h1>Site Title</h1>
    </header>
);
```

## Hooks

Prefix custom hooks with `use` and follow camelCase naming. eg: `useCart.js`

## Utils

Use camelCase and describe the utility's purpose. eg: `formatPrice.ts`
